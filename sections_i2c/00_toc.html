Mục lục chi tiết

Toàn bộ 48 slide — 5 phần (bìa + mục lục + nội dung).

Phần 1 — Bối cảnh & đặc tả I2C

  • Mục tiêu & phạm vi thiết kế I2C Master theo RD1139
  • Ràng buộc bus: open-drain, START/STOP, SDA đổi khi SCL = 0, clock stretching
  • Chuỗi giao dịch I2C: địa chỉ 7-bit + R/W, byte dữ liệu, ACK/NACK, STOP/RS
  • Chế độ Standard (100 kHz) / Fast (400 kHz) — liên hệ clock 32 MHz
  • Đối chiếu yêu cầu — checklist map tiêu chí → phần trình bày

Phần 2 — Kiến trúc RD1139 & RTL

  • Sơ đồ khối top module & luồng CPU → FSM → pad open-drain
  • Phân rã vai trò các khối: Processor IF, Filtered SDA/SCL, Slave model
  • Sơ đồ khối chức năng: clock gen & sync, start/stop, ACK, Tx/Rx data
  • Bus Control FSM (bit-level): block diagram, graph, giải thích chuỗi trạng thái
  • Master Control FSM (byte-level): block diagram, graph, giải thích chuỗi trạng thái
  • Trình tự ghi/đọc + Repeated START (RS) và ràng buộc

Phần 3 — Kiểm chứng & waveform

  • TB RD1139: kịch bản, tín hiệu cần quan sát
  • Checklist TX/RX/repeated START
  • Fig05–08: đọc timing & handshake phần mềm
  • Chứng minh mô phỏng — ảnh sóng + đối chiếu fig

Phần 4 — Thực thi ASIC (ref Sky130)

  • PDK Sky130, OpenLane, pipeline tổng hợp → sign-off
  • OpenCores Wishbone: map thanh ghi, phân cấp byte/bit
  • Đối chiếu RD1139 ↔ core tham chiếu silicon
  • STA/DRC/LVS/Antenna; kết quả run mẫu

Phần 5 — Kết luận, hạn chế, hướng mở rộng
