Giao thức I2C — master góc nhìn vận hành

Chuỗi giao dịch điển hình (7-bit addr)

  1. Bus idle: SCL, SDA đều cao (nhờ pull-up).
  2. Master phát START — chiếm bus.
  3. Byte đầu: 7 bit địa chỉ + 1 bit R/W (0 = write master→slave, 1 = read slave→master).
  4. Bit thứ 9: slave kéo SDA thấp = ACK, không kéo (để float high sau setup) = NACK tùy ngữ cảnh.
  5. Các byte sau: dữ liệu hoặc địa chỉ thanh ghi nội bộ (tùy thiết bị), mỗi byte kèm ACK/NACK.
  6. Kết thúc: STOP hoặc Repeated START (RS) để bắt đầu giao dịch mới không nhả bus bằng STOP.

Khái niệm liên quan đồ án

  • Đa master: nhiều master có thể treo trên cùng bus — cần arbitration (ưu tiên địa chỉ bit trên SDA).
  • Số byte giao dịch: do i_byte_cnt_reg và FSM master — sau đủ byte thì phát STOP (trừ kịch bản Abort).
  • Processor side: firmware ghi bit START vào thanh cấu hình, poll I2C_BUSY / TX_DONE / RX_DONE / cờ lỗi.
