Khối Nhiệm vụ
Processor Interface Đọc/ghi thanh ghi điều khiển/trạng thái; tạo xung chọn và handshake với bus nội bộ SoC (timing đặt theo clock hệ thống).
I2C Master Control FSM FSM mức byte: IDLE → START → SEND_ADDR → ADDR_ACK → TX_DATA / RX_DATA → DATA_ACK → STOP → DONE; phối hợp với bộ đếm byte.
I2C Bus Control FSM FSM mức bit trên bus: sinh START/STOP đúng điều kiện SCL; ACK bit.
Filtered SCL Kiểm soát pad SCL để nhận diện SCL.
Filtered SDA Đệm và dịch từng bit trong byte địa chỉ, dữ liệu và ACK/NACK.
I2C Slave I2C Slave mô phỏng theo tài liệu tham khảo RD1139.
