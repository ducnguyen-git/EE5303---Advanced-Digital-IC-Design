I2C Bus Control FSM — chuỗi trạng thái

Trạng thái Ý nghĩa vận hành
BUS IDLE Chờ lệnh; bus có thể rảnh hoặc chờ cấu hình.
START DETECT Kiểm tra tín hiệu START; chuẩn bị sinh điều kiện để START giao dịch.
SCL LOW Giữ SCL thấp để ổn định SDA trước khi đẩy bit dữ liệu.
SCL HIGH Đẩy bit dữ liệu; sau đó giữ SCL thấp để slave có thể kéo SDA xuống (clock stretching).
ACK DETECT / GENERATE Phát hiện ACK/NACK; sinh ACK/NACK.
STOP DETECT Phát hiện điều kiện STOP trên bus.
STOP GENERATE Sinh STOP khi đủ byte hoặc lỗi/abort.
DONE Báo hoàn tất giao dịch; set TX_DONE/RX_DONE; có thể về IDLE.
