Luồng phần mềm — config & status

i_config_reg — điển hình

  • START = 1 khởi động giao dịch; có thể tự clear sau khi nhận (theo RD1139/Word nhóm).
  • TX_IE / RX_IE — ngắt khi hoàn thành thay vì poll TX_DONE/RX_DONE.
  • INT_CLR — xóa pending sau ISR.
  • ABORT / RESET — hủy an toàn / đưa FSM về trạng thái đã định nghĩa.

o_cmd_status_reg

  • I2C_BUSY — giao dịch chưa kết thúc bằng STOP; set trước khi START auto-clear.
  • TX_DONE / RX_DONE — hoàn tất chuỗi byte theo hướng.
  • TX_ERR / RX_ERR — NACK, timeout… (theo RTL RD1139).
  • ABORT_ACK — xác nhận hủy từ phần cứng.

Dữ liệu: o_transmit_data_requested trước mỗi byte gửi; o_receive_data khi o_received_data_valid = 1.
