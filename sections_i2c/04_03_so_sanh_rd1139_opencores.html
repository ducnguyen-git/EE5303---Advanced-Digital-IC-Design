So sánh hệ thống: RD1139 (báo cáo) vs OpenCores (Sky130 ref)

Tiêu chí RD1139 / LaTeX nhóm Ref OpenCores + OpenLane
Giao tiếp host Processor Interface, tên i_* / o_* theo báo cáo. Wishbone: wb_adr_i, wb_dat_*, wb_ack_o, wb_inta_o.
Điều khiển giao dịch i_config_reg (START, IE, ABORT…), status o_cmd_status_reg. Thanh ghi cr (STA/STO/RD/WR), sr (busy, al, irq…), ctr (enable, interrupt enable).
FSM Tách rõ Master Control vs Bus Control (fig03–04). Byte FSM + Bit controller; chức năng tương đương nhưng tên trạng thái khác.
Đa master Đề cập phát hiện bus (Bus FSM). Có bit i2c_al, status arbitration lost.
Vai trò trong đồ án Đặc tả & hình lấy từ RD1139; silicon minh họa bằng core sẵn có đã P&R — trình bày trung thực, không gộp nhầm hai RTL.
