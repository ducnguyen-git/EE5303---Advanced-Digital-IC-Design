Kiểm tra luật thiết kế - DRC Flow

Quy trình Ký duyệt (Sign-off) DRC:

  • Inputs: Bản vẽ Layout định dạng GDSII kết hợp bộ thư viện luật thiết kế vật lý từ PDK.
  • DRC Checker: Công cụ (KLayout/Magic) phân tích layout, trả về file Log và file báo cáo XML thống kê vi phạm.
  • Layout DRC Debugging: Nạp file XML vào KLayout để đánh dấu trực tọa độ lỗi (markers) lên mặt nạ layout, giúp quá trình debug dễ dàng hơn.
