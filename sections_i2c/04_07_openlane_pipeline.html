Pipeline OpenLane (tổng quan bước)

  1. Synthesis (Yosys): RTL → netlist cổng; ràng buộc clock/reset.
  2. Floorplan + IO placement: định kích thước die, macro, vị trí pad.
  3. Placement: đặt cell; tối ưu timing sơ bộ, congestion.
  4. CTS (Clock Tree Synthesis): phân phối xung clock, cân skew.
  5. Routing: nối dây theo layer metal; fix DRC.
  6. Sign-off: STA (setup/hold), DRC, LVS, antenna rule; xuất GDS.

Ref README ghi lệnh dạng ./flow.tcl -design <dir> -tag <run> — mỗi tag là một tập báo cáo/reports riêng trong i2c/runs/.
