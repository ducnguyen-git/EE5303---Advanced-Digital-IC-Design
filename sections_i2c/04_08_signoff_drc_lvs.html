Sign-off: STA, DRC, LVS, Antenna

STA (Static Timing Analysis)

Kiểm tra setup và hold sau routing + SPEF; báo cáo WNS/TNS. Run “sạch” trong README ref: vi phạm 0 cho một số cấu hình clock.

DRC (Design Rule Check)

Khoảng cách metal, via, width — đảm bảo layout sản xuất được trên quy tắc sky130.

LVS (Layout vs Schematic)

So khớp netlist layout với netlist logic — phát hiện short/open/missing device.

Antenna rule

Hạn chế tích điện plasma làm hỏng cổng MOS trong quá trình etch — một số run ref ghi nhận vi phạm antenna (pins/nets).
